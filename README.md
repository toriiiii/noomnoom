# MakeUofT Project - NoomNoom

NoomNoom is an Arduino-coded, 3D printed robot that eats whatever you give it. Place an object in NoomNoom's "hand" and NoomNoom will toss it into its mouth.

NoomNoom was a project created for the make-a-thon MakeUofT. It was developed over the span of two days and entered into the "Useless Inventions" category.
